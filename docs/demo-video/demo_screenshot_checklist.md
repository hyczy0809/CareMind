**系统**：深色模式关闭，字体大小默认  
**前置条件**：加载演示数据（点击「加载 3 分钟演示数据」）

## 必须截图（核心流程）

### 1. Intro Carousel — 第 1 页（定位）

### 3. Intro Carousel — 第 3 页（开始）
- [ ] 截图：「你不是一个人在扛」大标题 + 「开始设置」按钮
- **用途**：情感共鸣配图

### 4. 智能记录 — 输入状态
- [ ] 截图：输入框已填入演示文字（「妈妈昨晚起来四次……」），「帮我整理」按钮可见

### 5. 智能记录 — 整理进度卡
- [ ] 截图：4 步进度全部打勾（整理今天发生的事 ✓ / 找出值得留意的地方 ✓ / ...）

### 6. 智能记录 — 结构化摘要卡
- [ ] 截图：睡眠「夜间起床 4 次」/ 行为「说有人偷钱」/ 饮食「只吃了几口」四行可见

### 7. 今日照护 — 关注事项卡（展开）
- [ ] 截图：左侧橙色竖条 + 「夜间安全」/ 展开状态 / 行动建议行列表 / 「已处理」「今天做不到」按钮

### 9. 复诊准备 — 照护摘要

## 截图规范

- 分辨率：原始尺寸，不缩放
- 状态栏：确保时间显示整数时间（如 9:41），信号满格，无通知
- 勿显示：真实个人信息、真实联系人、真实通知内容
- 文件命名：`caremind_[序号]_[内容简述].png`，如 `caremind_01_intro_positioning.png`
